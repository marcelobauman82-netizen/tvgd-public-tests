# TVGD — Exames Públicos

Este repositório reúne códigos públicos de validação da Teoria do Vácuo Gravitacional Dispersivo (TVGD).

A TVGD é apresentada aqui como uma teoria efetiva covariante de resposta estrutural do vácuo. O objetivo deste repositório não é declarar prova definitiva, mas disponibilizar uma cadeia reprodutível de testes falsificáveis.

## Cadeia principal de validação

Os testes principais cobrem:

1. Dinâmica galáctica e relação aceleração radial.
2. Universalidade da função estrutural \(P(u)=1-\exp(-u)\).
3. Testes externos fora do SPARC.
4. Lenteamento gravitacional fraco.
5. Cosmologia de fundo, CMB e crescimento linear.
6. Estabilidade, causalidade, PPN e velocidade das ondas gravitacionais.
7. Previsões falsificáveis.
