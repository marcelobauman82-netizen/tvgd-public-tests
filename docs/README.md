# TVGD Docs

Esta pasta contém documentação complementar do repositório público da TVGD.

Arquivos principais:

- `validation_map.md`: mapa dos testes públicos já criado.
- `known_limitations.md`: limitações conhecidas já criadas.
- `reproducibility_guide.md`: guia para instalar e rodar os testes.
- `data_sources.md`: fontes de dados usadas ou previstas.
- `falsifiability.md`: critérios de falsificação.
- `theory_summary.md`: resumo teórico da TVGD.

A documentação deve ser lida junto com o `README.md` principal do repositório.
